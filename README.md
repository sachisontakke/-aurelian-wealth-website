# Aurelian Wealth Partners

Premium React and Tailwind CSS website UI for a finance, investment, and wealth management brand.

## Design Concept

Aurelian Wealth Partners is designed as a trustworthy advisory experience for families, founders, executives, and professionals. The visual direction uses a restrained corporate palette, serif display typography, crisp cards, finance dashboard graphics, clear calls to action, and a lead-focused information architecture.

## Requirement Coverage

- Mandatory pages: Home, About Us, Services, Investment / Solutions, Contact Us
- Bonus pages and sections: Blog, Calculator, FAQ, Client Testimonials
- Home sections: Hero, About Overview, Services Overview, Why Choose Us, Investment Solutions, Testimonials, Process, CTA, Contact/Footer
- Features: Responsive layout, mobile navigation, smooth UI states, CTA buttons, icons and graphics, lead generation form, SEO metadata
- Stack: React, Vite, Tailwind CSS, HTML/CSS
